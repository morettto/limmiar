# Reprodução temporária

`criarReprodutor` posiciona e reproduz um HTMLAudioElement fornecido pelo
componente de revisão. O áudio é temporário, em memória. Este módulo não lê ou
escreve áudio em armazenamento e não reconstrói sessões a partir de arquivos.
Notas e transcrições históricas preservam suas âncoras de tempo em texto.
